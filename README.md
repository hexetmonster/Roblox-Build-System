# Roblox-Build-System
Somewhat customizable OOP build system.

## Features ##
* Modularity and flexibility
* Optimization!!!!
* Collision checking
* Rotation, scaling, and sledgehammer/deletion
* Undo and redo
* Server authority via remote functions
* Datastore capability (TODO)
* Segment/line-based tool (For walls or fences)
* Multi place (shift + left click)
* Mobile support (i think)
